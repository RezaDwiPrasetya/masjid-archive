# 07. User Stories

## Epic: Pengarsipan Laporan Mingguan

### US-001 — Mengunggah Laporan

**As a** bendahara **I want** mengunggah foto laporan mingguan beserta tanggalnya **So that** laporan tersimpan aman secara digital tanpa perlu mengubah cara pencatatan manual

#### Acceptance Criteria

- [ ] Bisa mengambil foto langsung dari kamera atau memilih dari galeri
- [ ] Wajib mengisi tanggal laporan sebelum bisa disimpan
- [ ] Muncul konfirmasi setelah berhasil disimpan

#### Priority

Must

#### Related Feature

F-001 Unggah Laporan

---

### US-002 — Melihat Arsip Tersusun Otomatis

**As a** pengurus DKM **I want** melihat daftar laporan tersusun per Tahun > Bulan > Minggu **So that** saya bisa menelusuri arsip lama tanpa perlu membuka buku fisik

#### Acceptance Criteria

- [ ] Arsip tampil dalam struktur accordion Tahun > Bulan
- [ ] Setiap laporan menampilkan tanggal Jumat yang jelas

#### Priority

Must

#### Related Feature

F-002 Arsip Laporan

---

### US-003 — Mencari Laporan

**As a** pengurus DKM **I want** mencari laporan lewat kata kunci dan filter Tahun/Bulan **So that** saya bisa menemukan laporan tertentu dengan cepat

#### Acceptance Criteria

- [ ] Hasil pencarian bisa difilter berdasarkan Tahun dan Bulan
- [ ] Hasil pencarian menampilkan tanggal laporan dan tanggal unggah

#### Priority

Must

#### Related Feature

F-003 Cari Arsip

---

### US-004 — Melihat Detail Laporan

**As a** pengurus DKM **I want** melihat foto laporan dalam ukuran penuh beserta detailnya **So that** saya bisa membaca isi laporan dengan jelas dan mengunduhnya jika perlu

#### Acceptance Criteria

- [ ] Foto ditampilkan dalam resolusi penuh
- [ ] Tersedia tombol unduh foto

#### Priority

Should

#### Related Feature

F-004 Detail Laporan
