# 04. User Journey

## Scenario

Bendahara menyelesaikan pencatatan laporan keuangan mingguan (tiap Jumat) dan perlu mengarsipkannya agar mudah dicari di kemudian hari.

| Stage     | User Action                                                                                                                       | User Thought                                     | Pain/Friction                        | Opportunity                                                         |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- | --------------------------------------- | ---------------------------------------------------------------------- |
| Trigger   | Selesai mencatat laporan Jumat mingguan di buku kas                                                                               | "Laporan ini harus disimpan supaya nggak hilang" | Tidak ada tempat penyimpanan digital | Ingatkan/arahkan bendahara untuk mengarsipkan tiap selesai mencatat |
| Discovery | Membuka aplikasi web Masjid Archive                                                                                               | "Semoga gampang, saya bukan orang IT"            | Takut ribet pakai aplikasi baru      | UI upload yang sangat sederhana, minim langkah                      |
| Action    | Memfoto halaman laporan, memilih tanggal laporan (Jumat), mengunggah — sistem otomatis menentukan tahun/bulan/minggu dari tanggal | "Tinggal foto dan pilih tanggal aja kan?"        | Salah pilih tanggal, foto buram      | Validasi tanggal, preview foto sebelum submit                       |
| Outcome   | Laporan tersimpan dan bisa dilihat/filter oleh pengurus lain                                                                      | "Sekarang gampang dicari kalau ada yang nanya"   | —                                    | Notifikasi konfirmasi upload berhasil                               |

## Key Opportunity

Titik dengan nilai terbesar ada di proses upload — harus sesederhana mungkin agar bendahara (yang tidak selalu familiar dengan aplikasi digital) tetap konsisten mengarsipkan setiap laporan mingguan.

## Desired Journey

Bendahara menyelesaikan pencatatan manual seperti biasa tiap Jumat → foto laporan → buka Masjid Archive → pilih tanggal → unggah dalam hitungan detik → pengurus lain bisa langsung memfilter dan melihat arsip kapan saja tanpa perlu menghubungi bendahara.
